# Compote

Lâche des fruits dans la caisse : deux fruits pareils qui se touchent fusionnent en un plus gros. De la cerise à la citrouille, sans dépasser la ligne.

Souris ou flèches : viser. Clic, espace ou flèche du bas : lâcher. Deux fruits identiques fusionnent ; deux citrouilles disparaissent avec un gros bonus. La partie s'arrête quand un fruit reste au-dessus de la ligne rouge.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Compote → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
